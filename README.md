# 3.SEATECH Web

Sitio corporativo de 3.SEATECH preparado para despliegue continuo en Cloudflare.

## Cloudflare
Conecte este repositorio desde Cloudflare, use la rama main y despliegue el directorio raíz. Es un sitio estático y no requiere comando de build.

## Arquitectura prevista
- www: frontend corporativo
- shop: comercio electrónico
- apps: aplicaciones
- api: backend privado mediante Cloudflare Tunnel

No almacene tokens, contraseñas, credenciales de pago ni secretos en este repositorio.
